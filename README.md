# Ancient Sites AI – static public demo

Static, server-less build of the Ancient Sites AI pilot PWA (AGPL-3.0-or-later). `shim.js` answers the app's `/api/*` calls from pre-generated JSON in `api/` (1,270 sites: 11 hand-checked pilot sites + UNESCO WHS from Wikidata, CC0).

Demo limitations: no AI answers (stored facts only), inscription reading disabled, find reports cannot be submitted, no admin/review area, no service worker install. The full app runs with `server.js`.
